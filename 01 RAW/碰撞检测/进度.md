# 碰撞检测学习进度

## 主题目标
基于无外力传感器的底盘碰撞与堵转检测（广义动量观测器与按轴判据）。

---

## 待攻克知识盲区清单

### 1. 核心理论盲区（当前攻坚重点）
- [ ] **观测器（Observer）的基本概念与机理**
  - [ ] 什么是状态观测器（State Observer）与扰动观测器（Disturbance Observer, DOB）？
  - [ ] 观测器作为“软传感器”的本质：如何利用已知控制输入、易测传感器输出与动力学模型，推算出不可测量的未知状态或外力？
  - [ ] 观测器误差反馈校正项的作用与收敛性原理。
- [ ] **拉格朗日建模法（Lagrange Method）**
  - [ ] 分析力学基础：为什么多自由度/多连杆系统采用能量法（拉格朗日法）优于牛顿-欧拉矢量受力分析法？
  - [ ] 广义坐标 $q$、系统总动能 $T(q, \dot{q})$ 与总势能 $V(q)$ 的列写规则；
  - [ ] 拉格朗日方程的标准推导流程：$\frac{d}{dt}\left(\frac{\partial L}{\partial \dot{q}}\right) - \frac{\partial L}{\partial q} = \tau$；
  - [ ] 质量惯性矩阵 $M(q)$ 的**对称正定性**机理；
  - [ ] 动量观测器核心数学前提：为什么 $\dot{M}(q) - 2C(q, \dot{q})$ 是反对称矩阵（即 $\dot{M} = C + C^T$）。

### 2. 动量观测器与动力学算法推导
- [ ] **广义动量观测器（GMO）的数学推导**
  - [ ] 广义动量定义：$p = M(q)\dot{q}$；
  - [ ] 如何利用反对称性质消除高阶角加速度 $\ddot{q}$（避免传感器噪声敏感的微分运算）；
  - [ ] 外力残差估计值 $r$ 的一阶低通滤波收敛表达式推导；
  - [ ] 欠驱动系统（Underactuated System）一般动力学方程向动量观测器的转化。
- [ ] **五自由度轮腿动力学与按轴解耦判据**
  - [ ] 五自由度广义坐标 $q = [s, \varphi, \theta_b, \theta_{lR}, \theta_{lL}]^T$ 的物理含义与相互耦合；
  - [ ] 按轴残差判据原理：为什么侧向拍击主导在 $\varphi$ 轴，正面冲击主导在 $s$ 轴；
  - [ ] 判定阈值设计与误报抑制机制（起步瞬态、地面打滑、通信采样抖动过滤）。

### 3. 控制决策与工程闭环
- [ ] 碰撞检测后的柔顺控制（如阻抗控制降低力矩输出、避免超功率罚分）；
- [ ] 严重堵转后的自动脱困状态机逻辑。
