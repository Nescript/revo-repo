本文记录概率论中容易出错的知识点与化简方法，每条包含易错点说明与正确处理。

## 并交混合运算的化简：$B\bar{C} \cup C$

**易错点**：遇到 $B\bar{C} \cup C$ 这类交、并、补混合的式子时，不知道如何化简，或认为无法继续化简。

**化简方法**：把 $C$ 看作整体，对 $C \cup (B\bar{C})$ 应用 [[事件运算律]] 中的分配律 $A \cup (BC) = (A \cup B) \cap (A \cup C)$：

$$B\bar{C} \cup C = (B \cup C) \cap (\bar{C} \cup C) = (B \cup C) \cap \Omega = B \cup C$$

其中 $\bar{C} \cup C = \Omega$（必然事件），见 [[对立事件]]；任何事件与 $\Omega$ 的交为其本身。

**结论**：$B\bar{C} \cup C = B \cup C$，即 $\bar{C}$ 部分是多余的，可以直接去掉。

## 并集的 "+" 记号仅适用于互斥事件

**规则**：只有当事件 $A$ 与 $B$ 互斥（即 $AB = \emptyset$）时，并事件 $A \cup B$ 才能记为和的形式 $A + B$。对一般（相容）事件，$A \cup B$ 不能写成 $A + B$。

**易错点**：把任意事件的并集都写成 "+" 的形式，或把 "+" 当作普通并集记号使用，忽略了它以互斥为前提。

相关概念见 [[互斥事件]]。
