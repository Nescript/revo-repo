# 广东工业大学计算机学院《概率论与数理统计》课程资料与历年试卷归档

本目录收录了**广东工业大学（GDUT）计算机学院**本科阶段《概率论与数理统计》课程的核心备考资料，重点整理了历年期末考试真题、官方标准答案与评分细则、指定教材课后习题详细解答以及高分复习笔记。

---

## 一、课程与考试特点概述

1. **计算机学院课程定位**：
   - 广工计算机学院（计算机科学与技术、软件工程、网络工程等专业）的概率论课程通常为 **56 学时**，期末统考对应 **A 卷**（或标注为「56 学时 A 卷」）。
   - 全校其他学院（如自动化、机电等）根据学时不同可能考 B 卷或 C 卷（C 卷通常学时更短、难度与考查范围较窄）。计算机学院备考应**优先以 A 卷和 56 学时真题为主**。
2. **教材与命题风格**：
   - 广工长期指定教材为原广工副校长、数学系教授**郝志峰**等编著的《概率论与数理统计》（科学出版社 / 高等教育出版社）。
   - 期末试题风格非常注重基础概念、计算能力与典型分布的应用，试题与教材课后典型习题、校内期末题库高度契合。
3. **试卷题型结构**（典型）：
   - 选择题（约 15~20 分）
   - 填空题（约 15~20 分）
   - 计算与证明大题（约 60~70 分）：
     - 古典概型与全概率/贝叶斯公式计算
     - 二维离散/连续型随机变量分布律、联合概率密度、边缘分布及条件分布
     - 随机变量函数的分布（卷积公式/分布函数法）
     - 数字特征（期望、方差、协方差、相关系数）计算
     - 参数点估计（矩估计法与最大似然估计法，历年必考压轴题之一）
     - 区间估计或假设检验基础

## 三、高效备考使用建议

1. **第一阶段：夯实教材与课后习题**
   - 广工概率论命题多处直接取材或变式于郝志峰编著《概率论与数理统计》课后习题。
   - 做题遇到卡点可直接对照 `教材习题详解与复习资料/概率论与数理统计_郝志峰_详细答案.pdf` 或 `习题详解/` 逐章解答。
2. **第二阶段：计算机学院专属卷模考**
   - 重点精做 `计算机学院期末真题/概率论与数理统计56学时A卷(含答案).pdf` 与 `56学时A 线上.pdf`，熟悉 56 学时卷的题量、难度与大题设问方式。
   - 结合 `计科同学期末复习考点总结笔记.pdf` 查漏补缺。
3. **第三阶段：多套历年真题限时演练与评分标准核对**
   - 抽取 `历年期末真题及标准答案(PDF版)/概率论与数理统计A.pdf` 及 Word 目录下近年份 A 卷进行 2 小时全真模拟。
   - 严格参照官方文档中的「**试卷参考答案及评分标准**」，注意大题的分步得分点（如：写出积分区域边界给分、换元步骤给分、似然函数取对数求导给分等），避免会做却失分。
