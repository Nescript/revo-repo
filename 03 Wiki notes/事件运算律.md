 
事件运算律是描述随机事件在进行并、交、差等复合运算时所遵循的代数等价变换规律。

## 基本运算律

### 交换律与结合律

- **交换律**：
  $$A \cup B = B \cup A, \quad AB = BA$$
- **结合律**：
  $$(A \cup B) \cup C = A \cup (B \cup C), \quad (AB)C = A(BC)$$

### 分配律

- **积对并的分配律**：
  $$A(B \cup C) = (AB) \cup (AC)$$
  当 $B$ 与 $C$ 互斥时，可记为：
  $$A(B + C) = AB + AC$$
- **并对积的分配律**：
  $$A \cup (BC) = (A \cup B) \cap (A \cup C)$$

（一个中心两个基本点）

### 对偶律（德摩根律）

对偶律描述了事件并与交的对立事件展开规律：

$$\overline{A \cup B} = \bar{A} \cap \bar{B} = \bar{A}\bar{B}$$

$$\overline{AB} = \bar{A} \cup \bar{B}$$

推广至有限个或可列个事件的情形：

$$\overline{\bigcup_{i} A_i} = \bigcap_{i} \bar{A}_i, \quad \overline{\bigcap_{i} A_i} = \bigcup_{i} \bar{A}_i$$

即“并的对立等于对立的交，交的对立等于对立的并”。

## 事件的互斥分解

任意事件 $A$ 可以分解为与事件 $B$ 相关的两个互斥部分的和：

$$A = AB + A\bar{B}$$

其中 $AB$ 与 $A\bar{B}$ 互斥（即 $(AB) \cap (A\bar{B}) = \emptyset$），该公式在全概率公式等推导中具有重要应用。
