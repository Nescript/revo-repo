# 实时性探索

本文档简要归纳与索引在机器人与工控高频闭环控制中，用于提升系统确定性与降低调度抖动的核心技术、项目与方法名称。

---

## 一、操作系统与内核方案 (OS & Kernel Level)

1. **Linux PREEMPT_RT**
   - **特点**：单内核宏改造方案，中断线程化（`irqthreads`）与可抢占锁（`rt_mutex`）。
   - **状态**：已正式合入 Linux 6.12+ 官方主线，工业界与现代机器人（ROS 2）的主流标准。
2. **Xenomai (Cobalt / Mercury / EVL)**
   - **特点**：双内核 / 伴生微内核方案，依托 Dovetail/I-pipe 中断管道优先拦截硬件中断。
   - **特点**：理论延迟极低（$1 \sim 3\,\mu\text{s}$），但存在次级模式切换（Mode Switch）陷阱，需配合专属 RTDM 驱动。
3. **RTAI (Real-Time Application Interface)**
   - **特点**：经典极简双内核方案，以 RTHAL 劫持中断向量，拥有理论上最极致的中断响应速度；因维护停滞，目前近乎遗留技术。

---

## 二、硬件物理分区虚拟化 (Partitioning Hypervisor)

1. **Jailhouse (西门子 Siemens 开源)**
   - **特点**：Type-1 静态物理分区 Hypervisor，空间切分硬件（AMP），绝不时分复用。
   - **性能**：启动后几乎“零 VM-Exit”，抖动 $< 1 \sim 2\,\mu\text{s}$，具备硬件级故障隔离（Linux 崩溃不影响实时核）。
2. **Bao Hypervisor**
   - **特点**：下一代轻量级独立静态分区微内核虚拟化方案（常用于 ARM 与 RISC-V 混合关键度系统）。

---

## 三、硬件与固件级调优 (Firmware & Hardware Level)

1. **SMI (System Management Interrupt) 抑制**
   - 禁用 BIOS Legacy USB Support、关闭主板风扇温控自动轮询，消除 SMM 模式（Ring -2）带来的 $50 \sim 500\,\mu\text{s}$ 硬件黑洞抖动。
2. **C-States 深度节能禁用**
   - 锁定 CPU 于 C0/C1 状态，禁止进入 C3/C6/C7，消除几十至数百微秒的睡眠唤醒延迟。
3. **P-States 动态变频与 Turbo Boost 禁用**
   - 禁用 Intel SpeedStep / Speed Shift (HWP)，锁定为固定最高主频（`performance` governor），防止动态温控降频。
4. **SMT / Hyper-Threading (超线程) 禁用**
   - 关闭逻辑超线程，确保每个核心物理独占 L1/L2 Cache 与流水线，避免并发干扰。

## 四、Linux 引导参数与核心隔离 (System & Boot Isolation)

1. **CPU 核心隔离 (`isolcpus`)**
   - 将专用控制核心（如 P-Core 3）从通用 CFS 调度域中彻底剥离。
2. **完全无滴答模式 (`nohz_full`)**
   - 核心独占单任务时，彻底停掉系统定时器周期性滴答（Tickless）。
3. **RCU 回调卸载 (`rcu_nocbs` / `rcu_nocb_poll`)**
   - 将内核 RCU 内存垃圾回收回调全部转移到非实时核心处理。
4. **轮询空闲等待 (`idle=poll`)**
   - 空闲时不执行 `hlt`/`mwait`，采用纯指令忙等，换取 0 纳秒唤醒。
5. **中断亲和性绑定 (`smp_affinity` / 停用 `irqbalance`)**
   - 将显卡、NVMe、通用网络等所有中断移出实时核心，实时网卡单独直通绑定。

---

## 五、工业总线与低延迟通信 (Fieldbus & Low-Latency I/O)

1. **RT-EtherCAT (实时以太网现场总线)**
   - 100Mbps/1Gbps 工业总线标准，支持分布式时钟（DC），微秒级主从站同步。
2. **SOEM (Simple Open EtherCAT Master)**
   - 基于 RAW Socket 套接字的用户态开源 EtherCAT 主站库。
3. **IgH EtherCAT Master (EtherLab)**
   - 配合原生内核网卡驱动（`ec_e1000e` / `ec_igb`）直接读写网卡 DMA 环的高性能主站。
4. **Kernel Bypass 内核旁路技术 (DPDK / AF_XDP)**
   - 绕过 Linux 协议栈直接在用户态轮询网卡收发环，削减网络 I/O 延迟。
5. **网卡中断聚合禁用 (`ethtool`)**
   - 关闭自适应中断合并（`rx-usecs 0 tx-usecs 0`）与硬件分段卸载（`gro/gso off`）。

---

## 六、机器人中间件与混合关键度架构 (Robotics & Middleware)

1. **ros_control / ros2_control**
   - 官方推荐运行在 PREEMPT_RT 上的硬实时硬件抽象与控制器插件框架。
2. **Orocos RTT (Real-Time Toolkit)**
   - 经典硬实时机器人控制组件框架（早期常构建于 Xenomai/RTAI 之上，并与 ROS 1 桥接）。
3. **Zephyr RTOS**
   - Linux 基金会旗下的工业级开源硬实时微内核操作系统（支持 x86 多核与 Jailhouse Inmate 模式）。
4. **micro-ROS**
   - 面向微控制器与 RTOS 的轻量级 ROS 2 中间件，支持跨系统 DDS 通信。
5. **IVSHMEM (Inter-VM Shared Memory)**
   - 跨虚拟机/跨分区的虚拟 PCI 共享内存通道，实现纳秒级跨核无锁数据交互。
